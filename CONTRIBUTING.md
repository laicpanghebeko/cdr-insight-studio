# Contribuer

1. Créez une branche depuis `main`.
2. Ajoutez ou mettez à jour des tests uniquement avec des données synthétiques.
3. Exécutez `make check`.
4. Ouvrez une pull request expliquant le format PDF ou le comportement concerné.

N’ajoutez jamais de listing réel, de logo client, de clé API ou d’identifiant personnel au dépôt. Les nouveaux parseurs doivent conserver les limites de taille et produire un message explicite lorsqu’un format n’est pas reconnu.
